# AI 生成 UI 执行指南

> 面向 AI（以及指挥 AI 的人）。目标：让一次生成的 UI 直接通过设计走查，不需要返工。
>
> 读之前先确认你已加载 `assets/tokens/source.json` 或 `assets/tokens/tokens.css`——本页所有色值都从那里来。

---

## 0. 五条最容易违反的规则

生成 UI 前先把这五条刻在脑子里：

| # | 规则 | 违反后果 |
| --- | --- | --- |
| 1 | 颜色只写 `var(--ds-semantic-*)` | 用色失控，无法统一维护 |
| 2 | 深海军蓝 `#034285` 系不用于通用组件 | 与后鲨吉祥物混淆，品牌与系统界面打架 |
| 3 | 数值与单位分开渲染 | 无法分别控制字号颜色，千分位后接中文单位排版不稳 |
| 4 | 趋势色是业务方向，不随证券惯例反转 | 「绿=涨红=跌」的预期错位 |
| 5 | 表格数值列右对齐 + 等宽数字 | 列不对齐，数据扫视困难 |

## 1. 配色决策树

```
要定一个颜色
  │
  ├─ 是背景/容器底？ → semantic.bg.*
  │     页面底 → bg.canvas
  │     卡片面 → bg.surface
  │     次级面(表头/禁用底) → bg.surface-subtle
  │     弱容器/菜单hover → bg.surface-muted
  │
  ├─ 是文字？ → semantic.text.*
  │     正文 → text.primary      辅助说明 → text.tertiary
  │     次要正文 → text.secondary  禁用 → text.disabled
  │     链接 → text.link
  │
  ├─ 是按钮/可点击态？ → semantic.action.*
  │     主 → action.primary-bg    次要 → action.secondary-bg
  │     文本 → action.tertiary-fg  危险 → action.danger-bg
  │
  ├─ 是状态提示？ → semantic.feedback.*
  │     success / warning / danger / info（各含 bg/border/fg 三档）
  │
  ├─ 是数据涨跌？ → semantic.trend.*
  │     正向 → trend.positive（绿）  负向 → trend.negative（红）  平 → trend.flat
  │
  ├─ 是图表？ → semantic.chart.series-1..6（按顺序，不按语义）
  │
  └─ 是吉祥物？ → semantic.mascot.*
        ⚠️ 仅用于后鲨形象、徽章、气泡、状态插画
```

**绝不做的事**：
- 写死 `#7C3AED` / `rgb(124,58,237)` → 必须 `var(--ds-semantic-action-primary-bg)`
- 写 `var(--ds-primitive-brand-600)` → primitive 层不开放给业务
- 调一个「差不多」的色 → 语义层已覆盖所有场景；找不到对应项说明需求特殊，先确认再扩展

## 2. 关键色值速查（供无 Token 环境时应急）

> ⚠️ 正式产物一律用 CSS 变量。以下仅供你无法加载 Token 时的临时理解。

| 语义 | 值 | 用途 |
| --- | --- | --- |
| 主色 | `#7C3AED` | 按钮、链接、选中、图表序列 1 |
| 主色 hover / active | `#6D28D9` / `#5B21B6` | 按钮状态 |
| 页面底 | `#F7F8FA` | 画布 |
| 卡片面 | `#FFFFFF` | 卡片、弹窗 |
| 主文字 | `#1B2028` | 正文 |
| 次文字 | `#454D5D` | 次要正文 |
| 三级文字 | `#616A7B` | 辅助说明 |
| 控件边界 | `#828B9B` | 输入框边框（≥3:1） |
| 正向 / 负向 | `#027A48` / `#B42318` | 趋势 |
| 后鲨主色 | `#034285` | ⚠️ 仅吉祥物 |
| 后鲨点缀 | `#EAC46D` | ⚠️ 仅吉祥物 |
| 后鲨墨色 | `#142D4F` | ⚠️ 描边、气泡文字 |

**后鲨专属色域**：色相 205–225 且明度 < 30% 的深海军蓝，通用组件禁用。

## 3. 间距

**只有 4px 的倍数**。档位：

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-1` | 4px | 图标与文字间隙 |
| `space-2` | 8px | 控件内间隙、标签间距 |
| `space-3` | 12px | 表单元素间距 |
| `space-4` | 16px | **默认组件间距** |
| `space-5` | 20px | 指标卡内边距 |
| `space-6` | 24px | **默认卡片内边距** |
| `space-8` | 32px | 区块间距、页面留白 |
| `space-12` | 48px | 页面标题与内容间距 |

**不要**用 5px / 7px / 9px / 10px 这类非整倍数。

**不要**用 margin 撑开卡片间距——用 grid 的 `gap`。

---

## 4. 排版

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 24px | 600 |
| 区块标题 | 18px | 600 |
| 卡片标题 | 16px | 600 |
| 正文 | 14px | 400 |
| 辅助说明 | 13px / 12px | 400 |
| 指标数值 | 28px | 600 |

- 行高：正文 1.6，标题 1.4，大标题 1.25
- 数值一律 `font-variant-numeric: tabular-nums`
- 中文与数字/英文之间留 1/4 空格

## 5. 组件选型表

| 需求 | 用什么 | 不要用什么 |
| --- | --- | --- |
| 触发操作 | `Button` | `<div onClick>` |
| 收集输入 | `Field` + `Input`/`Select`/`Textarea` | 裸 `<input>` + 手写 label |
| 容器分组 | `Card` + `CardHeader` | 手写 `<div>` + 边框 |
| 状态标识 | `Badge`（不可点） / `Tag`（可移除） | 纯色块 |
| 页面切换 | `Tabs`（≤7 项） | 一排按钮 |
| 提示信息 | `Alert`（页面级） / `Toast`（操作反馈） | `alert()` |
| 无数据 | `EmptyState`（有下一步指引） | 空白 |
| 加载中 | `Skeleton`（形状贴近真实内容） | 转圈 |
| 关键指标 | `MetricCard` | Card + 手写排版 |
| 折线/柱状图 | `ChartFrame` + SVG | 裸 `<svg>` 无容器 |
| 明细列表 | `DataTable` | `<table>` 手写 |
| 趋势数字 | `TrendValue` | 手写箭头 + 颜色 |
| 空状态插画 | `MascotState` | `EmptyState`（看板场景） |
| 引导提示 | `MascotBubble` | 顶部横幅 |

## 6. 看板生成模板

### 6.1 标准结构

```
页面头（标题 + 描述 + 主操作）
  ↓
筛选栏（全局筛选，放指标卡上方）
  ↓
指标卡区（4 列，ds-grid--4）
  ↓
主图表 + 侧栏洞察（ds-grid--3-2）
  ↓
明细数据表（ds-dtable）
```

### 6.2 指标卡硬规则

```tsx
<MetricCard
  label="总消耗"              // 13px/500/secondary
  value="286,430"              // 28px/600/tabular-nums
  unit="元"                    // 14px/tertiary，与 value 分开
  trend={{ value: '12.4%', direction: 'positive', comparison: '较上周期' }}
  spark={[12, 18, 15, 22, 19, 26, 31]}   // 可选
/>
```

- ❌ `value="286,430元"` —— 单位必须独立 prop
- ❌ 自己拼千分位 —— 组件不做格式化，在业务层做完再传
- ❌ 指标数值上色 —— 方向由 `trend` 单独表达

### 6.3 图表三条硬规则

1. **Y 轴从 0 开始**（除非明确标注截断）
2. **序列色按固定顺序** `series-1..6`，不按语义挑
3. **标题必须带维度**：「消耗趋势」不够，「消耗趋势 · 按日 · 近 30 天」才完整

### 6.4 图表 SVG 现成 class

| class | 用途 |
| --- | --- |
| `ds-chart__grid-line` | 网格线（**只画横向**） |
| `ds-chart__axis-line` | 轴线 |
| `ds-chart__axis-label` | 轴标签（12px，4.5:1） |
| `ds-chart__series` | 折线（2px 圆头） |
| `ds-chart__bar` | 柱状（圆角 2px） |

### 6.5 数据表规则

- 数值列 `numeric: true` → 右对齐 + 等宽数字
- 第一列是名称列，用 `renderName` 渲染（可带副标题）
- **不用斑马纹** —— 与悬浮高亮冲突
- 操作列固定右侧，按钮用 `ghost` 变体

## 7. 响应式

| 断点 | 行为 |
| --- | --- |
| ≥1280px | 完整布局 |
| 768–1279px | 指标卡降 2 列，侧栏型栅格降单列 |
| <768px | 全部单列，页面留白 16px，表格横向滚动 |

**降级只改列数，不改间距**（列间距恒 16px）。

---

## 8. 无障碍（生成时就要做，不是事后补）

| 项 | 要求 |
| --- | --- |
| 对比度 | 正文 ≥4.5:1，非文字 ≥3:1 —— 用 `check-contrast.mjs` 验 |
| 焦点环 | 2px 实线 + 2px 偏移，不可见则失去键盘导航 |
| 纯图标按钮 | 必须有 `aria-label` |
| 表单 | label 与 input 关联，不用 placeholder 代替 |
| 状态 | 不靠颜色单独传达，配文字或图标 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 文本缩放 | 200% 不破版 |

## 9. 后鲨（吉祥物）使用

### 9.1 只做三件事

1. **品牌标识** —— Logo 锁定区、页头
2. **引导解释** —— 气泡、引导
3. **状态插画** —— 空态、加载、异常

### 9.2 不做的事

- ❌ 不用后鲨色做按钮/标签/表格配色
- ❌ 不把后鲨色加进图表序列
- ❌ 不用后鲨色表达涨跌
- ❌ 不让后鲨成为纯图标按钮的唯一标识
- ❌ 不让后鲨占据栅格列

### 9.3 形态选择

| mood | 形象 | 用在 |
| --- | --- | --- |
| `happy` | 挥手欢呼 | Logo、加载、成功提示 |
| `excited` | 冲浪划水 | 引导、空状态、激活动态 |
| `serious` | 站立专注 | 异常提示、需用户处理 |
| `relaxed` | 坐姿休息 | 暂无更多内容、稍后提醒 |

## 10. 生成后自检清单

产出 UI 后逐条过：

- [ ] 所有颜色是 `var(--ds-semantic-*)`，没有硬编码
- [ ] 没有用后鲨深海军蓝做通用组件
- [ ] 数值与单位分开渲染
- [ ] 趋势用 `TrendValue`，符号与颜色同时出现
- [ ] 表格数值列右对齐 + 等宽
- [ ] 空态有下一步指引
- [ ] Y 轴从 0 开始
- [ ] 图表标题带维度
- [ ] 序列色按固定顺序
- [ ] 所有间距是 4 的倍数
- [ ] 纯图标按钮有 `aria-label`
- [ ] 表单有 label
- [ ] 焦点环可见
- [ ] 移动端单列不破版
- [ ] 跑过 `node scripts/check-contrast.mjs`
