# 间距与布局 · Spacing & Layout

## 1. 4px 基准

所有间距取 4px 的倍数。基准来自 4 的原因不是数学美感，而是：主流设备密度下 1 CSS px ≈ 1 物理 px，4px 是能同时被 2x/3x 屏整除的最小非零值；且 4/8/12/16/24 这组常用间距覆盖了绝大多数实际需求。

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `space-0` | 0px | 重置 |
| `space-1` | 4px | 图标与文字间隙、徽标内间隙 |
| `space-2` | 8px | 紧凑控件内间隙、标签间距 |
| `space-3` | 12px | 表单元素间距、按钮图标间隙 |
| `space-4` | 16px | **默认组件间距**、卡片内元素间距 |
| `space-5` | 20px | 图表标题与图表体间距、指标卡内边距 |
| `space-6` | 24px | **默认卡片内边距** |
| `space-8` | 32px | 区块间距、页面左右留白 |
| `space-10` | 40px | 空状态上下留白 |
| `space-12` | 48px | 页面标题与内容间距、空状态内边距 |
| `space-16` | 64px | 大区块分隔 |
| `space-20` | 80px | 页面底部留白 |
| `space-24` | 96px | 超大分隔 |

**缺失的档位说明**：刻意不提供 5px / 7px / 9px 这类非整倍数。间距不是连续量，档位越少越能保证一致性。

## 2. 组件间距默认值

| 场景 | 值 |
| --- | --- |
| 卡片内边距（默认） | `space-6` = 24px |
| 卡片内边距（紧凑） | `space-4` = 16px |
| 卡片内边距（无内边距） | 0，表格/图表自带内边距 |
| 卡片内元素间距 | `space-4` = 16px |
| 卡片头与内容间距 | `space-4` = 16px |
| 表单字段间距 | `space-4` = 16px（`Field` 内部 label/输入/辅助文字为 `space-2`） |
| 按钮内图标与文字 | `space-2` = 8px |
| 表格单元格横向 | `space-4` = 16px |
| 表格单元格纵向 | `space-3` = 12px |
| 指标卡内边距 | `space-5` = 20px |
| 页面左右留白 | `space-8` = 32px（桌面）/ `space-4` = 16px（移动） |
| 页面标题与内容 | `space-8` = 32px（桌面）/ `space-5` = 20px（移动） |
| 图表标题与图体 | `space-3` = 12px |
| 图表图例与图体 | `space-4` = 16px |

## 3. 栅格

### 3.1 断点

| Token | 值 | 设备区间 |
| --- | --- | --- |
| `breakpoint-xs` | 480px | 小屏手机 |
| `breakpoint-sm` | 768px | 平板竖屏 / 手机横屏 |
| `breakpoint-md` | 1024px | 平板横屏 / 小笔记本 |
| `breakpoint-lg` | 1280px | 桌面 |
| `breakpoint-xl` | 1536px | 大屏桌面 |

### 3.2 栅格预设

```html
<div class="ds-grid ds-grid--4">…</div>     <!-- 4 等列 -->
<div class="ds-grid ds-grid--3">…</div>     <!-- 3 等列 -->
<div class="ds-grid ds-grid--2">…</div>     <!-- 2 等列 -->
<div class="ds-grid ds-grid--2-1">…</div>   <!-- 2fr 1fr -->
<div class="ds-grid ds-grid--1-2">…</div>   <!-- 1fr 2fr -->
<div class="ds-grid ds-grid--3-2">…</div>   <!-- 3fr 2fr -->
```

列间距统一 `space-4` = 16px。

### 3.3 降级规则

| 栅格 | ≥1280px | 768–1279px | <768px |
| --- | --- | --- | --- |
| `--4` | 4 列 | 2 列 | 1 列 |
| `--3` | 3 列 | 2 列 | 1 列 |
| `--2` | 2 列 | 2 列 | 1 列 |
| `--2-1` | 2fr 1fr | 1 列 | 1 列 |
| `--1-2` | 1fr 2fr | 1 列 | 1 列 |
| `--3-2` | 3fr 2fr | 1 列 | 1 列 |

降级时**只改列数，不改间距**——保持 16px 列间距，避免切换断点时视觉密度突变。

## 4. 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-none` | 0px | 全屏容器 |
| `radius-xs` | 2px | 焦点环、极小徽标 |
| `radius-sm` | 4px | 复选框、菜单项、骨架屏 |
| `radius-md` | 6px | **按钮、输入框、标签**（默认） |
| `radius-lg` | 8px | 分段控件、筛选栏、反馈条 |
| `radius-xl` | 12px | **卡片、图表容器**（默认） |
| `radius-2xl` | 16px | 弹窗 |
| `radius-3xl` | 24px | 吉祥物气泡、大插画容器 |
| `radius-full` | 999px | 徽标、头像、开关、吉祥物徽章 |

**嵌套规则**：内层圆角 = 外层圆角 − 内边距。卡片（12px）内嵌 20px 内边距的按钮（6px），差值 6px 视觉协调；按钮用 12px 圆角嵌在卡片里会显得突兀。

## 5. 阴影与层级

| Token | 值 | 用途 |
| --- | --- | --- |
| `shadow-none` | none | — |
| `shadow-xs` | 1px 微弱 | 卡片静止态、菜单项、分段控件选中项 |
| `shadow-sm` | 1–3px | 输入框聚焦外的辅助元素 |
| `shadow-md` | 4–8px | 卡片悬浮态 |
| `shadow-lg` | 12–20px | 菜单、Toast、抽屉 |
| `shadow-xl` | 24–48px | 弹窗 |
| `shadow-focus` | 3px 半透明环 | 输入框聚焦 |
| `shadow-focus-danger` | 3px 危险色环 | 输入框聚焦 + 校验失败 |

**层级越高，阴影越大越弥散**。弹窗用 `xl` 而不是 `lg`，是为了在遮罩之上仍能明确区分。

阴影颜色统一用 `rgba(16, 20, 28, α)` 的冷黑，不使用纯黑——纯黑阴影在浅色界面上显得脏。

## 6. 布局结构

### 6.1 页面骨架

```
┌──────────────────────────────────────────────┐
│ 顶栏 / Sidebar（由产品定义，不在通用层）      │
├──────────────────────────────────────────────┤
│  页面标题 + 描述                    [主操作]  │  ← page__header
│                                              │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌───────┐  │
│  │ 指标卡  │ │ 指标卡  │ │ 指标卡  │ │ 指标卡 │  │  ← ds-grid--4
│  └────────┘ └────────┘ └────────┘ └───────┘  │
│                                              │
│  ┌──────────────────────┐ ┌───────────────┐  │
│  │ 主图表                │ │ 洞察列表      │  │  ← ds-grid--3-2
│  └──────────────────────┘ └───────────────┘  │
└──────────────────────────────────────────────┘
```

### 6.2 页面容器

```css
.ds-page {
  max-width: 1440px;
  margin: 0 auto;
  padding: 32px 32px 64px;
}
```

`max-width: 1440px` 的理由：超过 1600px 的内容宽度会让表格行的左右扫视距离过长，阅读效率下降。看板类页面内容密度高，比内容型页面更早触发这个限制。

## 7. 密度模式

看板的表格支持两档密度：

| 模式 | 行高 | 表头高 | 适用 |
| --- | --- | --- | --- |
| 默认 | 48px | 40px | 常规数据浏览 |
| 紧凑 | 36px | 36px | 同屏需要看到更多行 |

用 `ds-table--compact` 切换。行内按钮在紧凑模式下需要自带 `padding` 补偿点击区（见 [07-accessibility.md](07-accessibility.md)）。

## 8. 布局禁忌

| ❌ 禁止 | ✅ 应该 |
| --- | --- |
| 用 margin 撑开卡片间距 | 用 grid 的 gap |
| 用 `padding` 让元素「挤开」别的东西 | 用 flex/grid 的 gap 与 justify-content |
| 用 margin-bottom 做最后一项的间距 | 用 `:last-child { margin-bottom: 0 }` 或 gap |
| 硬编码 `width: 500px` | 用 `minmax(0, 1fr)` + max-width 约束 |
| 在组件里写绝对定位 | 用 flex/grid 布局 |
| 用 `z-index: 99999` | 用 `z-index` 分层 Token（见下表） |

### z-index 分层

| Token | 值 | 用途 |
| --- | --- | --- |
| `z-index-base` | 0 | 常规流 |
| `z-index-raised` | 10 | 卡片内悬浮层 |
| `z-index-sticky` | 100 | 吸顶表头 |
| `z-index-dropdown` | 300 | 下拉菜单 |
| `z-index-overlay` | 400 | 模态遮罩 |
| `z-index-modal` | 500 | 弹窗、抽屉 |
| `z-index-popover` | 600 | 浮层 |
| `z-index-toast` | 700 | 全局通知 |
| `z-index-tooltip` | 800 | 文字提示 |

只允许使用 Token，不允许写字面量。层级冲突时改 Token 值，不在组件里覆盖。
